# 평일 확인과 주말 복기

현재 로컬 시제품의 사용 순서입니다. 기록은 `.data/research.sqlite3`에 저장합니다.
화면은 같은 실제 자료와 저장 버전을 참조합니다.

## 평일: 확인 목록 살펴보기

1. 홈의 ‘오늘 확인할 근거’에서 확인 대상과 근거 변경 수를 봅니다.
2. ‘평일 확인·주말 복기’를 엽니다. ‘최신 기록 불러오기’로 현재 저장 상태를 갱신합니다.
3. 전체, 근거 변경, 예정일 도래, 원문 검토 대기 중에서 목록을 고릅니다.
4. ‘원문·근거 검토’에서 해당 자료를 확인합니다.

목록은 실제 정책·공시 후보·정책과 기업의 관계·실행 추적 기록을 대상으로 합니다.
가상 시연 분석은 목록에 포함하지 않습니다.
참조 변경을 먼저 표시하며, 그다음 재확인 예정일 순으로 정렬합니다.
정책·관계·공시 검토 버전이 바뀌면 연결 기록을 다시 확인하도록 표시합니다.
최근 수집 실패나 진행 중인 요청은 별도로 표시합니다.
같은 출처의 후속 수집이 성공하면 과거 실패를 현재 오류로 표시하지 않습니다.

확인 항목 수는 기회·위기 점수가 아닙니다.
목록이 비어 있어도 시장 위험이 없다는 뜻은 아닙니다.
앱을 열거나 기록을 새로 불러올 때 갱신합니다. 백그라운드 알림은 없습니다.

## 주말: 실제 근거에 답변 연결하기

1. 확인 목록의 ‘주말 답변 작성’을 누르거나 연결할 실제 기록을 선택합니다.
2. 연결된 질문과 근거를 확인합니다. 필요하면 원문 검토 화면으로 이동합니다.
3. 복기 질문, 내 답변, 다음 확인 조건, 재확인 예정일, 판단 이유를 입력합니다.
4. ‘주말 답변 저장’을 누릅니다.

답변은 사용자 해석입니다. 연결 기록의 신호를 표시하며 종목 신호를 변경하지 않습니다.
공시를 읽지 않고 복기만 저장해도 원문 검토가 완료되는 것은 아닙니다.
원문 검토 대기 항목은 원래 검토 화면에서 처리해야 합니다.
하나의 대상에는 하나의 주말 기록을 연결하며, 수정하면 새 버전이 추가됩니다.
이전 답변·이유·다음 조건·예정일은 남습니다.
예정일이 되거나 연결 근거가 바뀌면 다시 확인 목록에 표시합니다.

기존 ‘질문·복기 노트’는 가상 산업 분석에 연결된 연습 기록입니다.
실제 자료의 복기에는 새 ‘평일 확인·주말 복기’ 화면을 사용합니다.

## 과거: 저장 시점 조회하기

‘저장 시점 조회’에서 날짜를 선택하고 ‘당시 기록 조회’를 누릅니다.
한국시간으로 선택 날짜가 끝나기 전까지 저장된 실제 기록을 표시합니다.
공개일이 알려진 자료는 공개일도 해당 날짜 이내여야 합니다.
정책·공시·공시 검토·관계·실행 추적·새 주말 기록을 지원합니다.
가상 분석과 가상 문맥에 연결된 기존 노트는 포함하지 않습니다.

나중에 수집한 과거 공시는 과거 화면에 소급해 나타나지 않습니다.
참조한 정확한 버전이 해당 시점에 없으면 연결 기록도 제외합니다.
그날까지의 버전에서 질문·답변·신호·단계·다음 조건·변경 이유를 비교합니다.
현재의 검토 완료 상태를 과거 기록에 덧붙이지 않습니다.
공개일 미상 자료는 ‘저장 시각 기준’으로 표시합니다.
날짜만 있는 공개일은 한국시간 날짜로 취급합니다. 정확한 최초 공개 시각은 보장하지 않습니다.

이 기능은 앱의 저장 이력 조회입니다. 시장 전체의 당시 정보 재현이나 회귀 분석은 아닙니다.
해당 시점의 기록은 JSON으로 내보낼 수 있습니다.
전체 내보내기는 기존 질문 노트 화면에서도 제공합니다. JSON 가져오기는 없습니다.
