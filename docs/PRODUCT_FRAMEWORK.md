# 제품 기준 v1.0

기준일: 2026-10-17, 한국시간.
상태: 사용자 합의 기준. 구현 명세의 출발점.

## 목적과 유지 원칙

정책·산업·자금 흐름의 변화로 투자 생각을 점검합니다.
확인된 근거를 통해 기회와 위기를 구분합니다.
평일에는 짧게 확인하고, 주말에는 질문과 복기로 판단을 정리합니다.

사용자가 변경을 요청하기 전까지 공통 프레임과 종목 신호의 의미를 유지합니다.
기능 추가와 벤치마킹은 이 기준 안에서 진행합니다.
프레임 변경은 사용자 결정과 함께 버전 이력에 기록합니다.
이 문서는 자동 매매나 수익 보장을 목표로 하지 않습니다.

## 모든 분석 기능의 공통 프레임

**질문 → 근거가 있는 답변 → 신호 → 다음 확인 조건**

| 구성 | 필수 내용 |
|---|---|
| 질문 | 대상, 비교 기간, 판단할 조건 |
| 답변 | 결론, 지지 근거, 반대 근거, 불확실성 |
| 신호 | 현재 상태, 적용 규칙, 변경 이유 |
| 다음 확인 조건 | 관찰할 사건·지표, 확인 일정 또는 재확인 조건 |

출처 URL, 자료 기준일, 공개일, 수집일을 기록합니다.
확인된 사실, 기관·기업의 주장, AI의 해석, 사용자 가정을 구분합니다.
답변의 주장과 그 주장을 뒷받침하는 자료를 연결합니다.
요약 화면과 상세 화면은 같은 분석 기록과 버전을 사용합니다.

## 기능별 질문

| 기능 | 대표 질문 | 필요한 근거 |
|---|---|---|
| 정부 정책 | 정책이 실제 투자로 이어지는가? | 법령, 예산, 계약, 집행, 지연·축소 |
| 국가 간 확산 | 유사 정책이 시장을 더 키우는가? | 추가 수요, 투자 이전, 중복·과잉 공급 |
| 기술·경쟁 | 기술 변화가 경쟁력을 높이는가? | 검증, 고객 도입, 경쟁사의 대체 가능성 |
| 산업·기업 | 성장이 주문과 이익으로 연결되는가? | 수주, 매출, 이익률, 생산 능력 |
| 투자 주체 | 누가 자금을 늘리거나 줄이는가? | 자금 흐름, 보유 변화, 지속성, 자료 시차 |
| 과거 복기 | 유사 사례와 현재는 무엇이 다른가? | 당시 공개 정보, 이후 결과, 반례 |
| 내 자산 | 이 변화가 내 투자 조건에 어떤 영향을 주는가? | 비중, 공통 위험, 기간, 손실 시나리오 |

정부 지원금, 기업 설비투자, 증시 순매수는 서로 다른 자금 흐름입니다.
이를 합산하지 않습니다.
예산, 보증 한도, 민간 투자 목표, 실제 집행액도 구분합니다.

## 종목 신호등

| 코드 | 표시 | 의미 |
|---|---|---|
| opportunity | 🟢 기회 우세 | 확인된 근거에서 기회 요인이 우세 |
| mixed | 🟡 기회·위기 혼재 | 근거가 엇갈리거나 중요한 조건이 미확정 |
| risk | 🔴 위기 우세 | 투자 논리 훼손 또는 사업·가격 위험 근거가 우세 |
| insufficient | ⚪ 판단 보류 | 자료가 부족하거나 오래되어 비교가 어려움 |

기회는 매수 명령이 아닙니다. 위기는 매도 명령이 아닙니다.
신호 아래에 기회 근거와 위기 근거를 모두 표시합니다.
색상과 함께 문구·기호를 표시합니다.
자료 부족을 기회·위기 혼재로 숨기지 않습니다.
자료 만료 기준은 출처별 갱신 주기에 맞춰 정의합니다.
정확한 기준은 데이터 연결 단계에서 정합니다.

신호와 근거의 충분성은 별도 항목입니다.
근거가 풍부해도 기회와 위기가 엇갈릴 수 있습니다.
여러 기능의 신호 개수를 단순 합산하지 않습니다.
동일한 원문을 인용한 여러 기사를 독립 근거로 세지 않습니다.

비종목 질문도 신호의 판단 대상과 의미를 명시합니다.
예산 집행 진행률 자체를 특정 종목의 기회 신호로 취급하지 않습니다.
개별 종목 신호와 포트폴리오 영향은 별도 기록으로 유지합니다.

## 분석 기록에 필요한 항목

구현 시 다음 항목을 공통 기록으로 관리합니다.

- 대상 ID, 질문 ID, 분석 ID, 분석 버전.
- 답변, 기회 근거, 위기 근거, 불확실성.
- 원문 URL, 근거 위치, 자료 기준일, 공개일, 수집일.
- 현재 신호, 이전 신호, 적용 규칙 버전, 변경 이유.
- 다음 확인 사건, 예정일 또는 확인 조건.
- 사용자 투자 가설과 포트폴리오 영향.

새 분석은 이전 기록을 덮어쓰지 않습니다.
질문·대상·기준 시점이 같으면 화면마다 같은 분석을 참조합니다.
다른 시점을 비교할 때는 각 시점을 표시합니다.
정정 공시는 원본과 연결하고 정정 공개 시각을 보존합니다.

## 과거 분석 원칙

당시 정보 보기에는 해당 날짜까지 공개된 자료만 포함합니다.
사후 복기 보기에서는 이후 결과를 추가합니다.
13F의 보유 기준일과 공시일을 구분합니다.
13F로 정확한 매매일·매수가·전체 포트폴리오를 복원했다고 표현하지 않습니다.
가격 효과와 보유 수량 변화를 구분합니다.
주식 분할, 합병, 정정 공시를 반영합니다.
실패 사례와 상장폐지 자료의 누락 여부를 표시합니다.

## 화면과 구현 순서

지도, 차트, 타임라인을 중심으로 설명을 연결합니다.
질문과 답변은 해당 시각화의 근거를 공유합니다.

1. 첫 버전: 정책·산업 지도, 실행 추적, 보유자산 연결, 질문 노트.
2. 다음 단계: 신규 기업 발견, 투자 주체별 흐름, 13F 변화.
3. 데이터 검증 후: 장기 복기, 당시 정보 재현, 유사 사례 비교.

첫 버전부터 출처 시각과 분석 변경 이력을 저장합니다.
현재 기능들은 설계 상태입니다. 실제 수집·분석 완료로 표현하지 않습니다.

## 사용자 투자 조건

투자 기간은 1년입니다. 사용자가 제시한 손실 허용 범위는 −10%입니다.
이를 알림의 참고 조건으로 사용하며 손실 상한 보장으로 표시하지 않습니다.
−10%의 정확한 기준은 최초 자산·현재 자산·고점 대비 중 아직 확정하지 않았습니다.
위험 신호 규칙 구현 전에 손실 기준과 기준 통화를 확인합니다.
보유 종목과 현금은 사용자 입력으로 관리합니다. 시세로 검증된 값과 구분합니다.
사용자가 입력한 SpaceX/SPCX는 종목 식별이 독립적으로 검증되지 않았습니다.
검증 전에는 시세·공시를 자동 연결하지 않습니다.

## 완료 판단 기준

- 모든 분석 카드에 질문, 답변, 신호, 다음 확인 조건이 있습니다.
- 답변에서 원문 근거와 불확실성을 확인할 수 있습니다.
- 같은 분석은 홈·상세·알림에서 같은 신호를 표시합니다.
- 신호가 바뀌면 새 근거와 이전 판단의 차이를 확인할 수 있습니다.
- 자료 부족과 자료 만료 상태를 표시합니다.
- 과거 분석에 미래 공개 자료가 섞이지 않습니다.
- 종목의 기회·위기와 개인의 대응 판단을 구분합니다.
