# 아침 검증 안내

준비 기준: 2026-10-17, 한국시간. 검증 예정: 2026-10-18 아침.

## 실행

`Practice-Windows.bat`를 실행하세요. VS Code에서는 F5를 눌러도 됩니다.
브라우저가 `시작·검증 안내` 화면을 엽니다.
상단에 `연습 모드 · 개인 기록과 분리`가 표시되는지 확인하세요.
실행 전에 기존 연습 DB를 자동 백업합니다.

기존 연습 기록 59개 버전은 보존했습니다.
공식 자료 갱신과 작업 이력 21개 버전을 추가했습니다.
개인 DB의 파일 해시는 작업 전후 동일합니다.
연습 DB 무결성 검사 결과는 정상입니다.

## 15분 검증 순서

| 순서 | 조작 | 확인할 결과 |
|---|---|---|
| 1 | 시작 화면의 자료 상태 확인 | 정책·공시·검토 건수와 마지막 성공 시각 표시 |
| 2 | `공식 자료 한 번에 확인` 클릭 | 즉시 진행 상태 표시. 다른 화면으로 이동 가능 |
| 3 | 작업 완료 후 결과 확인 | 성공과 실패를 분리. 실패해도 기존 근거 보존 |
| 4 | `공시 후보 확인`에서 검토 전·주제·검색 사용 | 조건에 맞는 후보만 표시. 결과가 없으면 안내 표시 |
| 5 | 후보의 원문과 저장 본문 대조 | 질문·발췌·판단 보류·다음 확인 조건 확인 |
| 6 | 원문을 확인한 후보에 답변과 검토 이유 저장 | 새 검토 버전 추가. 종목 신호는 자동 변경하지 않음 |
| 7 | `질문·복기 작성`에서 실제 기록 선택 | 내 답변·다음 확인 조건·예정일을 저장 |
| 8 | 답변을 수정한 뒤 이전 버전 확인 | 이전 답변과 연결 근거 버전 보존 |
| 9 | 서버를 종료하고 다시 실행 | 저장한 연습 기록 유지 |
| 10 | `저장 이력 확인`에서 날짜 조회·JSON 내보내기 | 해당 날짜까지 저장된 자료만 표시 |

원문을 확인하지 못한 후보는 채택하지 않아도 됩니다.
검토 전 상태를 유지하는 것도 정상적인 결과입니다.

## 정책과 기업 연결 검증

정책 원문을 확인한 뒤 `정책·출처 관리`에서 검토를 완료하세요.
확인한 정책과 기업의 관계를 보여주는 출처가 있을 때만 관계를 등록하세요.
기업 공시를 채택한 뒤에는 관계 화면에서 정부 집행·기업 투자·가동·매출 단계를 별도로 기록할 수 있습니다.

현재 등록된 정책과 엔비디아 공시가 서로 관련 있다고 확정하지 않았습니다.
연결 근거가 없으면 관계를 만들지 마세요. 빈 연결 목록은 오류가 아닙니다.
테스트용 임시 DB에서는 관계 등록, 실행 추적, 참조 변경 후 재검토 흐름을 검증했습니다.

## 실제 출처 확인 결과

| 자료 | 이번 PC에서 확인한 결과 |
|---|---|
| SEC 엔비디아 공시 목록 | 10건 수신 |
| USAspending MICRON 검색 | 0건 응답 수신. 지원 부재를 뜻하지 않음 |
| 산업부 지정 정책 원문 | 수신 성공. 자동 검토 승인 없음 |
| SEC 최신 정기 공시 본문 재수집 | HTTP 403. 기존 저장 본문과 근거 후보 유지 |

SEC 본문 오류는 화면에 실패로 표시합니다. 실패를 수집 성공으로 처리하지 않습니다.
저장된 공시 후보로 검토·복기·이력 기능을 검증할 수 있습니다.
수집된 자료의 내용과 이용 조건 검토는 별도 작업입니다.

## 정기 확인과 재시도

자동 확인은 기본적으로 꺼져 있습니다.
시작 화면에서 `앱이 켜져 있는 동안 24시간마다 공식 자료 확인`을 선택하면 설정을 저장합니다.
앱 종료나 PC 절전 중에는 실행하지 않습니다.
다시 실행하면 지난 예정 작업을 한 번 확인합니다.

`실패·미완료만 재시도`는 앞선 묶음의 미완료 항목만 요청합니다.
같은 묶음은 시작 후 60초가 지나야 다시 요청할 수 있습니다.
서버가 비정상 종료된 작업은 마지막 진행 기록 10분 후 재시작할 수 있습니다.
오래된 작업 이력은 삭제하지 않습니다.

## 로드맵상 남은 범위

이번 작업은 실제 자료 검토와 반복 사용을 위한 개인 PC 검증 버전을 보완했습니다.
전체 분석 로드맵을 완료한 상태는 아닙니다.

- 실제 정책 6~10건과 보유 기업 공시 범위 확대.
- 원문 내용·데이터 이용 조건 검증과 사용자 근거 채택.
- AI 제공사·비용 결정 후 근거 기반 답변 초안 연결.
- 가격 제공사·기준 통화·손실 기준 결정 후 시세와 자산 위험 알림.
- 자료 축적 후 13F·장기 복기·회귀분석.

오류가 생기면 화면 이름, 누른 버튼, 표시된 오류 문구를 기록하세요.
앱의 자동 검토나 종목 매매 지시는 이번 버전의 기능이 아닙니다.
