## 아침 검증 버전 — 2026-10-17

시작·검증 안내 화면과 공식 자료 묶음 확인 기능을 추가했습니다.
공시 목록, 지원 검색, 지정 정책 원문, 최신 정기 공시 본문을 순서대로 요청합니다.
수집 중 다른 화면을 사용할 수 있고, 결과와 작업 이력을 버전으로 보존합니다.
실패·미완료 재시도, 중복 실행 방지, 사용자가 켜는 24시간 정기 확인을 제공합니다.
정기 확인은 앱 실행 중에만 동작합니다. PC 절전·종료 중에는 실행하지 않습니다.

공시 후보에 검토 상태·주제·본문 검색 필터를 추가했습니다.
지원 검색 종료일은 한국시간 수집일이며 실제 조회 조건도 스냅샷에 남깁니다.
같은 응답이라도 조회 조건이 다르면 별도 스냅샷으로 보존합니다.
실패한 최신 요청과 과거 성공 시각을 함께 보여 줍니다.

실제 재수집에서 남은 SQLite 커서가 오류 저장을 막는 문제를 수정했습니다.
이제 SEC 본문의 HTTP 403을 정상 기록하고 기존 본문을 보존합니다.
SEC 목록 10건, USAspending 0건 응답, 산업부 정책 원문은 실제 수신했습니다.
공시 본문 재수집은 실패했으며 수집 성공으로 표시하지 않습니다.

Windows에서 37개 테스트와 JavaScript 구문 검사가 통과했습니다.
데스크톱·모바일 화면의 오류와 가로 넘침을 확인했습니다.
연습 DB는 백업 후 실제 수집 이력만 추가했습니다. 기존 59개 버전은 그대로 보존했습니다.
개인 DB 파일 해시는 작업 전후 동일합니다.

실제 근거 채택과 정책·기업 연결은 사용자의 원문 검토를 기다립니다.
전체 로드맵 완료가 아니라 개인 PC의 실제 사용 검증을 위한 기능 묶음입니다.
실행과 확인 순서는 [아침 검증 안내](MORNING_CHECK.md)에 있습니다.

Windows에서 발견한 SQLite 연결 미종료와 한글 로그 인코딩 문제를 수정했습니다.

실행 전 SQLite 백업 API로 일관된 백업을 만들고 무결성을 확인합니다.
연습 DB는 최초 실행 때만 개인 DB에서 복사하며 재시작해도 기록을 유지합니다.
PC 안내 HTML에는 설치·실행·15분 검증·백업·복원·오류 해결을 담았습니다.
ZIP은 실제 DB 스냅샷을 포함하며 연습 DB·백업·환경 파일은 포함하지 않습니다.

Python 3.12 이상과 표준 라이브러리만 사용합니다.
Windows의 별도 시간대 DB 설치 없이 한국시간 UTC+09 날짜 계산을 지원합니다.
Linux에서 한글·공백 경로, 실행기 기동, DB 분리, 백업 무결성을 검증했습니다.
기존 브라우저 테스트를 포함한 28개 테스트가 통과했습니다.
Windows와 macOS에서의 직접 실행은 아직 검증하지 못했습니다.

사용자 답변 저장은 원문 검토 상태나 종목 신호를 바꾸지 않습니다.

과거 조회는 한국시간 하루 끝까지 앱에 저장된 실제 기록을 대상으로 합니다.
알려진 공개일이 미래인 자료와 해당 시점에 정확한 참조 버전이 없는 연결은 제외합니다.
나중에 수집한 자료는 과거 시점으로 소급하지 않습니다.
정책·공시·공시 검토·관계·실행 추적·주말 기록의 변경 이력과 시점 JSON을 제공합니다.
공개일 미상 자료는 저장 시각 기준으로 표시합니다. 시장 전체 정보 재현은 아닙니다.

실제 저장 DB에서는 정책 초안 1건과 공시 후보 11건이 확인 목록에 표시됩니다.
사용자 답변은 대신 작성하지 않았습니다. 수집 최신 상태에 미완료·오류는 없습니다.
화면 점검 중 잘못 덮어쓴 스타일 파일을 복구했고, 실제 CSS 적용 검증을 추가했습니다.

정책·기업 관계에 채택된 해당 기업의 공시 후보를 연결하는 기능을 추가했습니다.

원문 문맥과 해당 정책의 연결을 대조했다는 확인이 필요합니다.

현재 실제 정책은 검토 대기이고 공시 후보도 미채택이므로 실제 연결 기록은 만들지 않았습니다.

API 검증, 검토 변경 감지, 버전 충돌, 재시작 후 보존, 브라우저·모바일을 포함한 20개 테스트가 통과했습니다.

## 실제 접근 복구와 첫 정책 초안

공식 출처 세 곳의 재요청에서 텍스트 수신을 확인했습니다.
네트워크 초안 저장만으로 추정하지 않고 실제 요청 결과로 확인했습니다.
초기 프록시 차단 기록은 유지합니다.
USAspending은 제목만 수신했습니다. 개별 지출 자료는 확보하지 못했습니다.
SEC는 검색 화면을 수신했습니다. 개별 공시 수집은 아직 없습니다.

산업통상부 홈페이지에서 상세 보도자료 링크를 확인했습니다.
실제 제목은 “중견기업 성장을 위한 월드클래스 10大 날개 프로젝트 시작한다”입니다.
원문은 https://www.motir.go.kr/kor/article/ATCL3f49a5a8c/172296/view 입니다.
등록일은 2026-10-15입니다.
본문에서 원탁회의 출범, 과제당 최대 5년·1,000억 원 지원 방침을 확인했습니다.
2026년 말 후보 발굴, 2027년 선행연구, 2028년 선도과제 계획도 확인했습니다.
나머지 과제의 2029년 지원은 예산 당국 등과의 협의가 필요한 계획입니다.
확정 예산·실제 지급액·수혜 기업은 이 보도자료에서 확인하지 못했습니다.

상세 자료 수집 스크립트는 제목·등록일·본문 구간을 검증합니다.
본문 일부와 해시, 공개일·수집일, 요청 이력을 저장합니다.
정책은 계획 발표 단계와 판단 보류, 검토 대기로 등록했습니다.
사용자 검토를 대신하거나 관계·매매 신호를 자동 생성하지 않습니다.
같은 URL의 정책이 있으면 중복 생성하거나 내용을 덮어쓰지 않습니다.
정정 자료는 새 수신 자료로 보존되지만 정책 판단 갱신은 수동 검토가 필요합니다.

테스트 12개가 통과했습니다.
본문 경계, 잘못된 원문 거부, 재수집 중복 방지와 실패 이력을 추가 검증했습니다.
실제 수신 자료와 테스트용 응답은 서로 다른 DB에 보관했습니다.

## 후속 구현: 수집 상태와 수신 자료

공식 진입 페이지 3곳만 요청하는 수집 API와 상태 화면을 추가했습니다.
등록되지 않은 주소는 요청할 수 없습니다. 리디렉션은 자동으로 따라가지 않습니다.
TLS 검증을 유지하고 요청별 크기·소켓 대기 제한을 적용합니다.
수집 시작과 종료는 같은 요청 ID의 별도 버전으로 저장합니다.
서버 중단으로 종료 기록이 없는 요청은 완료로 표시하지 않습니다.
프록시 터널 403과 원격 HTTP 응답 오류를 구분합니다.

텍스트 수신 시 본문의 SHA-256과 최대 2,000자 발췌를 보관합니다.
같은 URL과 본문 해시는 자료를 중복 생성하지 않습니다.
각 요청 이력은 중복 여부와 관계없이 보존합니다.
원문 공개 시각은 추측하지 않으며 수집 시각과 분리합니다.
수신 자료는 개별 정책 근거가 아닌 검토 대기 진입 페이지로 표시합니다.
정책 초안으로 전달할 때 상세 URL·질문·답변·날짜는 사용자가 확인합니다.
저장한 정책은 참조 수신 자료 ID를 보존하고 검토 대기로 시작합니다.

실제 USAspending, motir.go.kr, SEC 요청은 모두 환경 프록시 차단으로 끝났습니다.
수집 이력은 DB에 기록했으며 실제 수신 자료는 없습니다.
총 10개 테스트가 통과했습니다. 성공 경로는 테스트 응답으로 검증했습니다.
임시 DB에서 중복 자료 방지, 재요청 제한, 정책 초안 연결도 검증했습니다.

환경 설정에서 제한 모드와 기존 사용자 도메인 목록이 비어 있음을 확인했습니다.
패키지 저장소 프리셋을 유지하고 다음 도메인만 초안에 추가했습니다.

- www.usaspending.gov
- www.motir.go.kr
- www.sec.gov

초안 저장은 현재 네트워크 정책 적용이나 발행을 뜻하지 않습니다.
사용자가 환경 설정을 검토·저장하고 발행한 뒤 실제 접근을 다시 확인해야 합니다.

## 후속 구현: 정책·기업 연결 근거

정책·기업 연결 화면과 API를 추가했습니다.
사용자 검토가 완료된 정책에만 관계를 등록합니다.
공급 가능성, 계약 확인, 간접 영향, 부정적 영향을 구분합니다.
계약 확인에는 사용자의 원문 대조 확인이 필요합니다.
이는 시스템 자동 검증이나 투자 신호를 의미하지 않습니다.
관계의 질문·답변·다음 조건, 출처·발췌·공개일을 저장합니다.
참조한 정책 버전과 관계의 변경 이유도 보존합니다.
수정은 새 버전으로 추가하고 철회도 별도 버전으로 기록합니다.

정책 버전이 달라지면 기존 관계에 재검토 필요를 표시합니다.
기업 상세와 정책 상세에서 같은 관계 기록을 표시합니다.
가상 정책과 식별 미확인 SpaceX / SPCX에는 관계를 등록하지 않습니다.
동일 정책·기업의 활성 관계를 중복 등록하지 않습니다.
철회된 관계는 이력으로 남으며, 활성 관계로 표시하지 않습니다.
종목 신호는 실제 기업 분석 자료가 연결되기 전까지 판단 보류입니다.

기존 기능을 포함한 8개 테스트가 통과했습니다.
브라우저에서 관계 생성, 종목 연결, 정책 변경 후 재검토, 철회를 확인했습니다.
API에서 계약 대조 조건, URL, 중복 등록, 버전 충돌, 재시작 보존을 검증했습니다.
환경의 소켓 제한 때문에 테스트는 승인된 샌드박스 외 실행으로 수행했습니다.
실제 자료 자동 수집과 기업 영향 분석은 아직 미구현입니다.

## 공식 사이트 안내 정정 · 2026-10-17

사용자는 USAspending, `https://www.motir.go.kr/`, SEC EDGAR의 정상 동작을 확인했습니다.
산업부 안내 주소는 `motie.go.kr`에서 `motir.go.kr`로 수정했습니다.

대체 CHIPS 주소는 아직 검증하지 않았습니다.
수정된 산업부 주소를 포함한 세 사이트에 이 환경에서 다시 접근했습니다.
세 요청 모두 환경 프록시의 403을 반환했습니다.
사용자 브라우저의 정상 동작과 실행 환경의 수집 실패를 별도로 표시합니다.
프록시 403은 원격 페이지의 존재 여부를 검증한 결과가 아닙니다.

## 후속 구현: 정책·출처 관리

정책·기관·HTTPS 출처·발췌·사건일·공개일을 직접 등록할 수 있습니다.
질문·답변·다음 확인 조건·등록 이유를 같은 기록에 보존합니다.
모르는 날짜는 비워 두며 임의로 생성하지 않습니다.
실행 단계는 계획, 예산, 공고, 계약, 집행, 가동, 지연, 축소, 취소를 지원합니다.

등록 자료는 검토 대기 상태로 저장합니다.

자동 수집이나 실제 정책 원문 등록은 완료하지 못했습니다.
앱 DB에는 검증하지 않은 실제 정책이나 테스트 입력을 넣지 않았습니다.

검토 전 지도 제외, 원문 대조 확인, 검토 완료 반영, 수정 후 검토 초기화를 검증했습니다.
보완 요청, 위험한 URL 거부, 날짜 검증, 버전 충돌과 재시작 보존도 검증했습니다.

## 검증 결과

브라우저 테스트와 API 테스트를 포함한 4개 테스트가 통과했습니다.

- 홈에서 정책 상세와 종목 상세로 이동했습니다.
- 산업 분석 v1을 선택해 이동한 뒤에도 같은 버전을 확인했습니다.
- 실제 자료가 없는 종목의 판단 보류 상태를 확인했습니다.
- 국가 필터로 정책 목록을 좁혔습니다.
- 현금 상대 금액 수정 후 비중과 시나리오가 재계산됐습니다.
- 노트 생성·수정 후 이전 버전이 남았습니다.
- 서버 재시작 후 같은 DB의 기록과 버전을 확인했습니다.
- 오래된 버전으로 저장하면 충돌 응답을 확인했습니다.

- 사용자 입력 HTML을 실행하지 않고 텍스트로 표시했습니다.

- 모바일 390px 화면에서 여섯 화면의 가로 넘침이 없었습니다.
