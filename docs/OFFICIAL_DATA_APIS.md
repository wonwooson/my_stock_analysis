# 공식 데이터 API 연결

확인일: 2026-10-17, 한국시간.

## SEC

[SEC 공식 API 안내](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)를 확인했습니다.
엔비디아의 고정 CIK 0001045810에 대한 제출 이력 API를 연결했습니다.
응답 CIK와 NVDA 티커를 대조합니다.
최근 목록에서 10-K·10-Q·8-K 및 정정 공시를 최대 10건 선택합니다.
공시 접수번호, 보고 기준일, 제출일, 접수 시각, 원문 링크를 저장합니다.
응답 배열의 길이와 문서 경로를 검증합니다.
실제 주요 공시 목록 10건을 수신했습니다.
목록 수집과 아래 본문 수집은 별도 단계입니다. 실적 수치와 정책 수혜는 아직 분석하지 않습니다.
과거 추가 이력 파일은 아직 조회하지 않습니다.

## USAspending

[공식 저장소 API 계약](https://raw.githubusercontent.com/fedspendingtransparency/usaspending-api/master/usaspending_api/api_contracts/contracts/v2/search/spending_by_award.md)을 확인했습니다.
POST 검색은 읽기 작업이며 외부 자료를 변경하지 않습니다.
검색 조건은 다음과 같습니다.

- 기간: 2024-01-01~2026-10-17.
- 지원 기관: Department of Commerce.
- 수혜자 검색어: MICRON.
- 지원 유형: 02·03·04·05, 보조금 범주.
- 첫 페이지 최대 10건. 전체 데이터 집계가 아닙니다.

초기 이름 검색에서는 MICRONESIA 관련 수혜자가 섞였습니다.
기관 필터와 MICRON 단어 경계 검사를 추가했습니다.
기관·기업명 검사를 통과해도 상장사·자회사·CHIPS 연결을 자동 확정하지 않습니다.
수정된 실제 검색 결과는 0건입니다.
다른 지원 유형, 기간, 기관, 법인 식별자로 조회하면 결과가 다를 수 있습니다.
정책 지원이 없다는 결론을 내리지 않습니다.

Award Amount와 Total Outlays는 별도 필드로 저장합니다.
금액은 USD이며 정확한 소수 문자열로 보존합니다.
빈 값, 0, 음수 조정을 구분합니다.
검색 기간의 현금 지급 합계처럼 합산하지 않습니다.
Last Modified Date는 실제 응답의 날짜·시간을 지원합니다.
원문 값도 저장하고, 시간대 없는 값을 UTC로 간주하지 않습니다.

## 저장과 검증

공식 API 원본 JSON과 해시, 검색 조건, 수집 범위를 스냅샷으로 저장합니다.
공시·지원 기록은 식별자 기준으로 연결합니다.
변경된 필드가 있을 때만 새 버전을 추가합니다.
같은 자료를 재수집한 요청 이력은 계속 보존합니다.
응답 검증 실패 시 잘못된 레코드를 일부만 반영하지 않습니다.
현재 데이터와 과거의 특정 수집 실행 결과는 다를 수 있습니다.
원문 수신은 검토 완료나 기회 신호를 의미하지 않습니다.

실제 응답에서 날짜 형식 오류를 발견하고 수정했습니다.
잘못된 응답, 정정 공시, CIK 불일치, 금액 누락·0·음수, 기업명 오탐을 테스트했습니다.
기존 브라우저 사용 흐름을 포함한 테스트 19개가 통과했습니다.

## 네트워크

홈페이지와 API는 다른 호스트입니다.
기존 허용 목록을 보존하며 data.sec.gov와 api.usaspending.gov를 설정 초안에 추가했습니다.
초기 API 요청은 환경 프록시 403으로 차단됐습니다.
이후 실제 수집기 실행에서는 두 API 모두 응답을 받았습니다.
접근 성공과 초안 발행 상태는 별개입니다. 환경 발행 완료를 확인한 것은 아닙니다.

## 다음 검증

SEC 후보의 문맥을 검토하고 현금흐름표·기간·단위를 대조하는 기능으로 확장합니다.
USAspending은 법인 식별자와 지원 프로그램을 확인한 뒤 검색 범위를 확장합니다.
지원 유형과 검색어를 늘리기 전에 공식 정의와 데이터 범위를 대조합니다.

## 공시 본문·근거 후보

[실제 수신한 엔비디아 10-Q](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000075/nvda-20260726.htm)는 2026-08-26 제출 자료입니다.
보고 기준일은 2026-07-26입니다.
HTML 본문에서 정규화한 서술 문단 510개와 근거 후보 11개를 저장했습니다.
주제별 최대 5개 후보를 표시합니다. 중복 문단은 같은 주제 안에서 제외합니다.
60~5000자 문단만 검사하며 표·숨김 XBRL은 제외합니다.
AI 분석이 아닌 영어 키워드 검색이며, 수치 추출과 정책 수혜 판정은 수행하지 않습니다.
검색 누락과 문맥상 무관한 후보가 있을 수 있습니다.

검토 화면은 질문·답변·판단 보류·다음 조건을 유지합니다.
채택에는 원문 대조 확인이 필요하며, 채택·제외·재검토 이력은 추가 버전으로 저장합니다.
종목 신호는 자동 변경하지 않습니다.
동일 HTML 해시는 중복 본문을 만들지 않습니다. 변경된 본문은 별도 기록으로 저장합니다.
저장 본문은 정규화 텍스트이며 원본 HTML 전체는 아닙니다.
과거 본문과 검토 기록은 JSON 내보내기에 포함됩니다. 화면은 최신 본문의 후보를 표시합니다.
