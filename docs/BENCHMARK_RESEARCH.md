# 벤치마킹 조사와 적용 후보

조사일: 2026-10-17, 한국시간.
기준 문서: [제품 기준 v1.0](PRODUCT_FRAMEWORK.md).

## 조사 범위와 한계

공식 사이트에 HTTPS 접근을 시도했습니다.
아래 사이트는 모두 환경 프록시에서 `403 Forbidden`으로 차단됐습니다.
최신 페이지, 요금, API, 데이터 저장·재배포 권한은 확인하지 못했습니다.
아래 기능 설명은 기존에 알려진 서비스 성격을 바탕으로 한 1차 조사입니다.
직접 사용한 결과나 현재 제공 기능의 검증 결과가 아닙니다.
우리 앱 적용안은 별도의 설계 제안입니다.

## 참고 대상

| 서비스·공식 출처 | 알려진 참고 기능 | 우리 앱 적용 후보 | 후속 검증 |
|---|---|---|---|

| [Koyfin](https://www.koyfin.com/) | 시장 대시보드, 비교 차트, 관찰 목록 | 정책·산업·종목의 기간을 맞춘 비교 화면 | 한국 데이터 범위, 과거 기간, 데이터 권한 |
| [TradingView](https://www.tradingview.com/) | 차트, 관찰 목록, 조건 알림 | 사건을 차트에 표시하고 근거 변화에 알림 연결 | 사건 표시 방식, 알림 조건, 임베드·데이터 권한 |

| [Quiver Quantitative](https://www.quiverquant.com/) | 정부 계약, 정치·기업 관련 대체 데이터 | 정부 지출과 기업 연결의 근거 탐색 | 계약 데이터 출처, 범위, 갱신 주기, 연결 정확도 |
| [USAspending](https://www.usaspending.gov/) | 미국 연방 지출·수혜자·계약 정보 | 정책에서 실제 수혜자와 자금 집행으로 이동 | 의무부담·실제 지급 구분, 하위 수혜자, 수정 이력 |
| [Global Trade Alert](https://www.globaltradealert.org/) | 국가별 무역·산업 정책 개입 자료 | 국가·산업·정책 수단별 비교 | 국가별 포괄성, 정책 상태 정의, 라이선스 |
| [FRED](https://fred.stlouisfed.org/) / [ALFRED](https://alfred.stlouisfed.org/) | 경제 시계열과 제공 지표의 과거 발표본 | 당시 알려진 수치와 이후 수정치 분리 | 지표별 과거 발표본 범위, 재배포 조건 |
| [SEC EDGAR](https://www.sec.gov/edgar/search/) | 공식 공시 원문·제출 이력 | 원문·정정·공시일을 보존하는 기준 자료 | 자동 수집 정책, 13F 대상 범위와 구조 |

USAspending과 SEC는 분석 제품보다 원천 자료의 참고 대상입니다.
웹사이트 열람 가능성과 앱의 데이터 이용 권한은 별개입니다.
서비스 구독이 API나 재배포 권한을 자동으로 포함한다고 가정하지 않습니다.

## 적용 우선순위 제안

P0는 공통 프레임을 유지하는 기반입니다.
P1은 데이터 연결 후 추가할 기능입니다.
P2는 이력의 품질을 검증한 후 추가할 기능입니다.
이 우선순위는 제안이며 구현 완료를 의미하지 않습니다.

| 우선순위 | 기능 | 답할 질문 | 답변·신호 연결 | 완료 조건 |
|---|---|---|---|---|
| P0 | 근거 패널 | 이 답변을 무엇으로 확인할 수 있는가? | 지지·반대 근거, 원문, 시점 표시 | 모든 핵심 주장에 근거 또는 미확인 표시 |
| P0 | 신호 변경 이력 | 지난번과 무엇이 달라졌는가? | 이전 답변·신호와 새 근거 비교 | 변경 이유와 적용 규칙 버전 확인 가능 |
| P0 | 정책 실행 타임라인 | 실제 돈과 계약이 움직였는가? | 발표·예산·계약·집행을 구분 | 원 계획과 최신 상태를 동시에 확인 |
| P0 | 공통 질문 카드 | 화면마다 판단이 일치하는가? | 동일 분석 ID·버전 재사용 | 홈·상세·알림의 신호 일치 |
| P0 | 자료 시각 보존 | 이 자료를 언제 알 수 있었는가? | 기준일·공개일·수집일 저장 | 미래 공개 자료를 과거 판단에서 제외 가능 |
| P1 | 국가 정책 비교 | 추가 수요인가, 투자 이전인가? | 금액 성격과 현지 조달 조건 비교 | 중복 발표와 비교 불가 금액을 구분 |
| P1 | 관찰 조건·알림 | 무엇이 바뀌면 다시 살펴봐야 하는가? | 다음 확인 조건과 알림 연결 | 기사 중복 없이 조건 변화만 통지 |
| P1 | 기관 보유 변화 | 운용사는 어떤 노출을 바꾸었는가? | 수량·평가액·공개 시차 분리 | 분할·정정과 가격 효과 처리 |
| P2 | 당시 시점 재현 | 당시 정보로도 같은 판단이 가능한가? | 당시 답변과 사후 복기 분리 | 공시 지연·통계 수정·누락을 표시 |
| P2 | 유사 사례 비교 | 현재와 과거의 결정적 차이는 무엇인가? | 공통 조건과 반례를 함께 표시 | 성공 사례만 선택하지 않고 자료 누락 공개 |

## 참고하되 도입하지 않을 방식

- 설명 없는 종합 점수와 자동 매수·매도 결론.
- 유명 투자자의 보유를 현재 매수 신호로 직접 변환하는 방식.
- 발표액·보증 한도·민간 유도 목표를 합친 투자 규모.
- 기사 수를 근거의 개수로 간주하는 방식.
- 시뮬레이션 결과를 실제 운용 성과로 표시하는 방식.
- 데이터가 없을 때 중립 신호로 숨기는 방식.

## 후속 조사 절차

1. 공식 제품·도움말 문서에서 후보 기능의 제공 여부를 확인합니다.
2. 동일한 정책 사례로 출처, 일정, 변경 이력, 수혜 기업 연결을 비교합니다.
3. 13F 사례에서는 보유 기준일과 공시일의 표시를 확인합니다.
4. 시계열 사례에서는 수정 전 수치를 조회할 수 있는지 확인합니다.
5. API, 자동 수집, 보존, 표시, 재배포 조건을 구분해 기록합니다.
6. 확인된 기능과 우리 앱의 설계 제안을 각각 갱신합니다.

공식 사이트를 읽을 수 있는 네트워크 접근이 있어야 후속 검증을 완료할 수 있습니다.
접근을 위해 현재 설정의 허용 목록을 임의로 확대하지 않았습니다.
