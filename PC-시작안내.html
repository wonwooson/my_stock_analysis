결 · PC에서 먼저 사용해 보기

이 파일은 시작 안내입니다. 앱은 아래 실행 파일로 엽니다.

1. 준비

  1. ZIP 파일을 모두 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
  2. Python 공식 사이트에서 Python 3.12 이상을 설치합니다. 추가 라이브러리는 필요하지 않습니다.
  3. 압축을 푼 폴더를 사용자 계정이 쓸 수 있는 위치에 둡니다. 관리자 권한은 필요하지 않습니다.

2. 연습 모드로 시작

PC실행 파일
WindowsPractice-Windows.bat 더블클릭
macOSPractice-Mac.command 실행
Linux폴더에서 터미널을 열어 sh start-linux.sh --practice

브라우저가 열리면 상단의 연습 모드 · 개인 기록과 분리를 확인하세요. 창이 열리지 않으면 터미널에 표시된 주소를 같은 PC의 브라우저에 입력합니다. 실행할 때마다 포트가 달라질 수 있습니다.

macOS에서 실행 권한 문제로 열리지 않으면 터미널에서 해당 폴더로 이동하여 bash Practice-Mac.command를 실행하세요. 보안 차단을 일괄 해제할 필요는 없습니다.

3. 15분 사용성 검증

  1. 평일 확인: 확인 목록을 보고 무엇을 먼저 읽어야 할지 이해되는지 확인합니다.
  2. 공시 근거 검토: 후보 1개에서 질문·발췌·원문·다음 조건을 확인합니다. 실제 원문을 대조한 경우에만 채택합니다.
  3. 주말 복기: 실제 기록을 선택해 내 답변과 이유를 작성합니다. 재확인 예정일을 오늘로 저장해 목록에 나타나는지 확인합니다.
  4. 답변 수정: 다른 답변과 이유로 다시 저장합니다. 이전 버전이 남는지 확인합니다.
  5. 과거 조회: 오늘 날짜와 자료 저장 이전 날짜를 조회합니다. 두 결과가 다른지 확인합니다.
  6. 재실행: 터미널에서 Ctrl+C로 종료한 뒤 연습 모드를 다시 실행합니다. 작성한 답변이 남아 있는지 확인합니다.

연습 모드에서도 원문 링크와 수집 버튼은 인터넷을 사용합니다. 저장된 자료만 열람하고 답변을 쓰는 작업은 외부 데이터 연결 없이 가능합니다. 최신 시세·AI 답변·자동 종목 판단은 아직 제공하지 않습니다.

4. 개인 모드로 사용

Windows는 Start-Windows.bat, macOS는 Start-Mac.command, Linux는 sh start-linux.sh를 실행합니다. 상단에 개인 모드가 표시됩니다.

연습 기록은 개인 기록으로 자동 합쳐지지 않습니다. 처음 연습 모드를 실행할 때 개인 DB를 복사하고, 이후에는 연습 기록을 이어서 사용합니다.

저장·백업·종료

  • 개인 기록: .data/research.sqlite3
  • 연습 기록: .data/practice.sqlite3
  • 실행 전 자동 백업: .backups 폴더. 기존 DB가 있을 때 만들어집니다. 백업은 자동 삭제하지 않습니다.
  • 종료: 실행한 터미널에서 Ctrl+C. 브라우저만 닫으면 서버는 계속 실행됩니다.
  • 복원: 서버를 종료하고 현재 DB를 다른 이름으로 보관한 뒤, 원하는 백업을 해당 DB 경로로 복사합니다.

같은 디스크의 자동 백업은 PC 고장에 대비한 별도 백업이 아닙니다. 서버 종료 후 폴더를 신뢰하는 별도 저장소에도 복사하세요. 폴더에는 보유 비중과 개인 답변이 있으므로 공유하지 마세요.

실행이 안 될 때

  • Python 오류: python --version 또는 python3 --version이 3.12 이상인지 확인합니다. Windows에서는 py -3 --version도 가능합니다.
  • Windows에서 Python이 없다는 창이 뜨면 공식 Python 설치를 확인합니다.
  • 폴더 저장 권한 오류: 압축을 모두 풀었는지, 사용자 폴더에 저장했는지 확인합니다.
  • 원문 수집 실패: 저장 자료 열람은 계속할 수 있습니다. 수집 상태 화면에서 오류를 확인하세요.
  • 직접 실행: Windows py -3 launch.py --practice, macOS/Linux python3 launch.py --practice.

이 실행기는 같은 PC에서만 접속하도록 설정했습니다. 공유기 포트 개방이나 방화벽의 공용 네트워크 허용은 필요하지 않습니다.

검증 범위: Linux에서 실행·브라우저·백업·연습 데이터 분리 검증. Windows·macOS 실행 파일은 제공하지만 해당 OS에서 직접 실행한 결과는 아직 없습니다.
