# 시장 흐름 리서치 앱

정부 정책, 산업 변화, 자금 흐름을 연결하는 투자 리서치 앱을 설계합니다.
평일에는 변화를 확인합니다. 주말에는 근거와 과거 사례를 검토합니다.

현재는 로컬 웹 시제품을 실행할 수 있습니다.
열두 화면에서 정책·출처·기업 관계, 수집 상태, 자산 시나리오, 버전별 질문 노트를 제공합니다.
공식 사이트 진입 페이지, 산업통상부 상세 보도자료 한 건, 엔비디아의 주요 공시 목록 10건을 수신했습니다.
AI 답변과 실제 종목 신호 산출은 아직 연결하지 않았습니다.

## 개인 PC에서 개발

[개인 PC 개발 안내](docs/LOCAL_DEVELOPMENT.md)를 확인하세요.
VS Code F5는 연습 모드로 실행합니다. 전체 검증은 `Tasks: Run Test Task`에서 실행합니다.
프로젝트 Python은 `.venv/Scripts/python.exe`입니다.

## PC에서 사용성 검증

[PC 시작 안내](PC-시작안내.html)를 브라우저로 여세요. Python 3.12 이상이 필요합니다.
Windows는 `Practice-Windows.bat`, macOS는 `Practice-Mac.command`로 연습 모드를 실행합니다.
Linux는 `sh start-linux.sh --practice`를 실행합니다.
브라우저가 자동으로 열리고, 사용 가능한 로컬 포트를 선택합니다.
개인 모드는 `Start-Windows.bat`, `Start-Mac.command`, `sh start-linux.sh`입니다.

연습 기록은 `.data/practice.sqlite3`에 저장하며 개인 기록과 분리합니다.
기존 DB는 실행 전에 `.backups`에 백업합니다. 백업을 자동 삭제하지 않습니다.
앱을 종료하려면 터미널에서 Ctrl+C를 누르세요.
PC 안내에는 15분 검증 순서, 복원 방법, 실행 오류 해결 방법이 있습니다.
Windows와 Linux에서 실행기 테스트를 수행했습니다. macOS 직접 실행은 아직 검증하지 않았습니다.
Python 추가 패키지 없이 한국시간 날짜 계산이 동작하도록 구성했습니다.
재배포용 ZIP은 `python scripts/build_pc_bundle.py`로 생성합니다.
ZIP에는 개인 DB 사본이 포함되므로 공개 공유하지 마세요.

## 개발 환경에서 실행

Python 3.12 이상에서 다음 명령을 실행하세요. 앱 실행에 추가 패키지는 필요하지 않습니다.

```bash
cd C:\Market_Analysis
python server.py --port 8000
```

서버는 로컬 인터페이스의 8000번 포트에서 실행됩니다.
클라우드 온보딩 화면은 로컬 웹 미리보기를 지원하지 않습니다.
[홈 화면 이미지](docs/screenshots/home.png)와 [모바일 자산 화면](docs/screenshots/mobile-portfolio.png)에서 구성을 확인할 수 있습니다.

기록은 `.data/research.sqlite3`에 저장됩니다. 이 파일은 Git에서 제외합니다.
다른 DB를 사용하려면 `--db /absolute/path/research.sqlite3`를 지정하세요.
서버 재시작은 기존 기록을 보존합니다. 초기 가상 자료도 중복 생성하지 않습니다.
사용자 노트와 자산 수정은 이전 버전을 지우지 않고 추가합니다.
질문 노트 화면에서 전체 기록을 JSON으로 내보낼 수 있습니다.
JSON 내보내기는 열람·보관 용도입니다. JSON 가져오기 기능은 아직 없습니다.
DB를 복사해 백업할 때는 먼저 해당 서버를 종료하세요.
복사한 DB를 `--db`에 지정하면 같은 기록을 열 수 있습니다.

## 검증

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

API 테스트는 Python 표준 라이브러리로 실행됩니다.
브라우저 테스트는 Playwright가 설치한 Chromium을 사용합니다.
프로젝트 전체 검증 명령은 `.venv/Scripts/python.exe scripts/verify.py`입니다.
Playwright가 없으면 브라우저 테스트만 건너뜁니다.
개인 Windows PC에서 브라우저 테스트를 포함한 29개 테스트가 모두 통과했습니다.

## 현재 구현 범위

- 홈, 정책 지도·필터, 실행 타임라인, 종목 상세, 자산, 질문 노트.
- 공통 가상 산업 분석의 버전 선택과 원문 설명서 연결.
- 실제 자료가 없는 종목은 판단 보류. 산업 신호와 종목 신호 분리.
- 상대 금액 수정, 비중 계산, 반도체 묶음의 변동 시나리오.
- 사용자 질문·답변·신호·확인 조건 저장, 이전 버전 열람, 충돌 감지.
- 실제 근거의 검토 대기·참조 변경·재확인 예정일을 모은 평일 확인 목록.
- 실제 자료에 연결된 주말 답변과 재확인 일정, 답변·참조 버전 보존.
- 한국시간 날짜별 앱 저장 이력 조회, 미래 자료·누락된 참조 버전 제외, 시점 JSON 내보내기.
- 출처 공개일과 실제 기록 시각 분리, 사용자 기록과 가상 문맥 구분.
- 정책·기관·출처 URL·발췌·사건일·공개일 수동 등록.
- 검토 대기 → 사용자 원문 대조 → 검토 완료 또는 보완 요청.
- 검토 완료 자료만 정책 지도와 홈에 반영. 수정 시 다시 검토 대기.
- 출처·답변·정책 단계·검토 사유의 이전 버전 보존.
- 정책·기업 관계 등록: 공급 가능성, 계약 확인, 간접 영향, 부정적 영향.
- 관계별 원문·발췌·질문·답변·다음 조건과 참조 정책 버전 보존.
- 정책 실행 추적: 정부 집행·기업 투자·가동·공급·매출 반영별 공시 근거 연결.
- 채택된 동일 기업 공시를 지지·반대·불확실로 검토하고, 참조 변경 시 재검토 표시.
- 정책 변경 시 재검토 표시, 관계 철회, 이전 관계 이력 열람.
- 공식 진입 페이지 3곳의 수집 요청, 시작·종료·응답·오류 기록.
- 수신 텍스트 일부 보관, 동일 본문 중복 방지, 정책 초안으로 전달.
- SEC 최근 공시 API: 엔비디아의 10-K·10-Q·8-K 및 정정 최대 10건.
- USAspending API: 미 상무부·MICRON 이름·보조금 검색, 첫 페이지 최대 10건.
- API 응답 스냅샷, 검색 조건, 금액·날짜 검증, 변경 이력 보존.
- 엔비디아 공시 서술 문단에서 설비투자·정책 지원·수출 규제·구매 약정 후보 추출.
- 후보별 원문, 질문, 답변, 다음 확인 조건, 채택·제외 검토 이력 보존.
- [공시 근거 검토 화면](docs/screenshots/filing-evidence.png). 키워드 추출이며 신호는 판단 보류.

가상 분석 이력은 과거 시점 재현 엔진이 아닙니다.
AI 답변, 자동 신호, 범용 공고 탐색, 공시 수치 분석, 가격 차트, 수출입·13F·회귀분석은 후속 작업입니다.
수집 화면은 공식 진입 페이지를 요청합니다. 상세 자료 수집은 확인된 산업통상부 보도자료와 엔비디아 SEC 공시를 지원합니다.
요청은 자동 예약하지 않으며 같은 출처에 60초 간격 제한을 적용합니다.
초기 요청 3건은 환경 프록시 403으로 차단됐습니다. 이 실패 기록은 보존합니다.
후속 재요청에서는 세 사이트의 텍스트 수신을 확인했습니다.
홈페이지 수집과 별도로 실제 데이터 API를 연결했습니다.
SEC에서는 엔비디아의 최근 주요 공시 목록 10건을 수신했습니다. 최신 10-Q 본문 한 건에서 근거 후보 11개를 추출했습니다.
USAspending의 수정된 검색 조건은 0건을 반환했습니다. 지원이 없다는 뜻은 아닙니다.
지원 금액과 실제 지급액은 별도 필드입니다. 빈 값은 0으로 대체하지 않습니다.
산업통상부의 2026-10-15 월드클래스 10대 날개 프로젝트 보도자료는 실제 정책 초안으로 등록했습니다.
이 정책은 검토 대기이며 예산 확정이나 집행 완료로 표시하지 않습니다.
특정 상세 자료 재수집은 `python scripts/import_motir_policy.py`로 실행할 수 있습니다.
이 스크립트는 고정된 공식 URL의 제목·등록일·본문 구조를 검사합니다.
검사 실패는 이력으로 남기고, 기존 정책을 덮어쓰지 않습니다.
수동 출처 등록은 시스템의 원문 수집·검증을 뜻하지 않습니다.
출처 검토 완료도 종목의 기회 신호를 자동 생성하지 않습니다.
공개 배포용 인증은 없습니다. 로컬 단일 사용자 시제품으로 사용하세요.

- [평일 확인·주말 복기 사용법](docs/REVIEW_WORKFLOW.md): 실제 기록 확인, 답변 저장, 과거 시점 조회.
- [제품 기준 v1.0](docs/PRODUCT_FRAMEWORK.md): 사용자와 합의한 공통 구조와 신호 정의.
- [구체 기획안 v0.1](docs/PRODUCT_PLAN.md): 화면, 첫 버전 범위, 수집·저장 구조, 개발 단계와 출시 기준.
- [시제품 구현 기록](docs/PROTOTYPE_STATUS.md): 기술 선택, 검증 결과, 후속 작업.
- [공식 데이터 API 연결](docs/OFFICIAL_DATA_APIS.md): 명세 출처, 검색 범위, 실제 결과와 한계.
- [벤치마킹 조사](docs/BENCHMARK_RESEARCH.md): 참고 서비스, 적용 후보, 검증 한계.
- [작업 지침](AGENTS.md): 이후 작업에서 유지할 규칙.

문서는 현재 작업공간에 저장했습니다.
Git 커밋과 원격 저장소 반영은 별도 작업입니다.
